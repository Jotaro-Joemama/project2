# DiceForge

DiceForge is a command-line tabletop dice roller written in Python.

## Part 1 features

- Roll standard dice: d4, d6, d8, d10, d12, d20, and d100.
- Roll multiple dice, such as `2d6`.
- Add or subtract a modifier, such as `1d20+3` or `4d8-1`.
- Receive clear feedback when an expression is invalid.

## Run the program

1. Install Python 3.
2. Open a terminal in this project folder.
3. Run:

   ```bash
   python main.py
   ```

## Example expressions

- `d20`
- `2d6+3`
- `4d8-1`
- `3d100`

## Project development

This repository is being developed in milestones. Part 1 establishes the dice classes,
expression parsing, and command-line interaction. Later milestones will add saved
roll history, JSON presets, and automated tests.
